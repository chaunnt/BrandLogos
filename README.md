# Brand Logos in Vietnam

Open [index.html](index.html) in a browser to browse the catalog. Each available
logo has local SVG, PNG and JPEG downloads. The PNG and JPEG images are
monochrome renderings on a white background; the SVG is the original vector.

The logo artwork comes from [Simple Icons](https://simpleicons.org/), which
publishes its icons under [CC0 1.0](https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md).
Brand names and logos remain trademarks of their respective owners. Check the
owners' guidelines before using them. The page lists requested brands whose
artwork is not yet available.
